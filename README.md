# procamera-web
Support, privacy policy, terms and landing page for Expo: Vintage Film Camera (iOS), formerly ProCamera.

Published from `codiee-dev/procamera-web` with GitHub Pages (`main`, `/`), the same
shape as the other codiee sites: plain HTML, one `style.css`, light and dark from the
system. The source lives in `pro-camera-ios/Web/procamera-web/`; edit there and copy
over.

| Page | App Store Connect field / use |
| --- | --- |
| `index.html` | Marketing URL |
| `support.html` | Support URL |
| `privacy.html` | Privacy Policy URL; linked from the paywall and Settings |
| `terms.html` | Linked from the paywall; add to the App Description or the EULA field |

The App Store link on `index.html` uses app id `6835460148` and 404s until release.
